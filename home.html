function checkEligibility(lastDonationDate) {
  if (!lastDonationDate) return { isEligible: false };
  
  // 1. Calculate time delta in milliseconds
  const diffInMs = Date.now() - new Date(lastDonationDate).getTime();
  
  // 2. Convert to calendar days
  const daysPassed = Math.floor(diffInMs / (1000 * 60 * 60 * 24));
  const isEligible = daysPassed >= 120; // 4 Months
  
  return {
    isEligible,
    daysPassed,
    daysRemaining: isEligible ? 0 : (120 - daysPassed)
  };
}

Important physiological and compatibility guidelines for blood donors and recipients.

The human body needs approximately 120 days to fully replenish red blood cell counts and restore iron reserves after a standard 450ml donation. Our system enforces this safety threshold automatically.

O Negative (O-) is the Universal Donor because its red blood cells lack A, B, and Rh antigens, making it safe for anyone in emergency trauma. AB Positive (AB+) is the Universal Recipient because it can safely receive blood from any group.

Data is stored using structured JavaScript Arrays of Objects with automatic persistence via browser localStorage, delivering lightning-fast execution without external database lag.
