2. CORE STRUCTURED PROGRAMMING CONCEPTS
================================================================================

Q1: What is Structured Programming, and how does your project implement it?
Answer:
Structured Programming is a programming paradigm based on 3 control pillars:
1. Sequence: Sequential line-by-line execution.
2. Selection (Condition): if-else and switch-case branching for blood compatibility.
3. Iteration (Repetition): for/while loops traversing donor arrays (avoiding goto).

In our project: Every feature is modularized into independent functions:
- checkEligibility()
- searchDonor()
- registerDonor()
- deleteDonor()
- getCompatibleBloodGroups()


Q2: What Data Structure did you use to store donor information?
Answer:
We used an Array of Composite Objects / Structures.

In JavaScript:
donorDatabase = [
  { id: 1, name: "Rahim Uddin", bloodGroup: "A+", lastDonation: "2026-05-10", phone: "01711223344", city: "Dhaka", age: 26, gender: "Male" },
  ...
];

In C Language Equivalent: Array of Structures (struct Donor):
struct Donor {
    int id;
    char name[50];
    char bloodGroup[5];
    char lastDonation[15]; // "YYYY-MM-DD"
    char phone[15];
    char city[50];
    int age;
    char gender[10];
};

struct Donor donorDatabase[100];
int totalDonors = 8;


Q3: How is Modularity achieved in your project?
Answer:
Modularity follows "Divide and Conquer". Instead of monolithic code, we wrote 
dedicated functions where each module does one job:
- checkEligibility(date): Pure date difference calculation.
- getCompatibleBloodGroups(group): Lookup dictionary table.
- searchDonor(criteria): Linear loop filter.
- registerDonor(data): Validation and array append.
- deleteDonor(id): Array deletion & shift.

3. ALGORITHMS & MATHEMATICAL LOGIC
================================================================================

Q4: How does the 120-Day (4-Month) Cooldown Calculation work?
Answer:
It uses Epoch Timestamp Arithmetic (milliseconds since Jan 1, 1970):
1. Delta: diffInMs = Date.now() - new Date(lastDonation).getTime()
2. Days: daysPassed = Math.floor(diffInMs / (1000 * 60 * 60 * 24))
3. Check: isEligible = (daysPassed >= 120)
4. Remaining: daysRemaining = isEligible ? 0 : (120 - daysPassed)


Q5: What Search Algorithm is used, and what is its Time & Space Complexity?
Answer:
Linear Iterative Search Algorithm (using for loop):
- Time Complexity: O(N) where N is total donors.
- Space Complexity: O(M) where M is matched result array. Auxiliary space is O(1).
- Latency: In-memory RAM lookup takes < 1 ms.


Q6: How does the Blood Compatibility Matrix logic work?
Answer:
Based on ABO & Rh antigen-antibody biology:
- O- (Universal Donor): Can donate to all 8 groups; can only receive from O-.
- AB+ (Universal Recipient): Can receive from all 8 groups; can only donate to AB+.

Matrix Table:
A+  -> Receives from: A+, A-, O+, O-
A-  -> Receives from: A-, O-
B+  -> Receives from: B+, B-, O+, O-
B-  -> Receives from: B-, O-
AB+ -> Receives from: All 8 Groups (Universal Recipient)
AB- -> Receives from: AB-, A-, B-, O-
O+  -> Receives from: O+, O-
O-  -> Receives from: O- (Universal Donor)

Tricky Q2: "What happens when you delete a donor from the middle of the array?"
Answer:
"When a donor is deleted via splice(index, 1) (or array shifting in C), 
all subsequent elements shift left by 1 index to keep contiguous memory allocation."

C Code:
void deleteDonor(int index, int *total) {
    for (int i = index; i < *total - 1; i++) {
        donorDatabase[i] = donorDatabase[i + 1];
    }
    (*total)--;
}
