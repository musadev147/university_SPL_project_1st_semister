1. Project Overview & Problem Statement

The Blood Donor Management ERP System (HemoPulse) is a lightweight, responsive web-based application designed to manage blood donor records efficiently. Built using structured programming principles in Vanilla JavaScript, the system demonstrates the practical application of modular logic, composite data structures (Arrays of Objects), and linear search algorithms to solve a critical healthcare problem: emergency blood transfusion matching and donor eligibility tracking.

2. Core Technical Architecture & Features

• Donor Registration Module: Enrolls new donors into memory arrays with essential attributes including Name, Blood Group, Contact, and Last Donation Date.
• ERP Command Dashboard: Displays donor records in structured tabular layouts with real-time analytics and blood group inventory matrices.
• Biological Matching Engine: Evaluates compatibility between all 8 ABO/Rh blood groups using structured lookup maps and linear iteration.
• Real-Time Eligibility Engine: Calculates time differences in milliseconds (Δt) to enforce the mandatory 120-day (4-month) donor cooldown interval.

3. Modular Function Specification
Function SignatureERP PurposeUnderlying Programming Concept

checkEligibility(donationDate) Verifies 4-month (120-day) physiological cooldown. Date arithmetic, Epoch time conversion, Math functions.
getCompatibleBloodGroups(group) Returns valid transfusion donor groups for recipient. Hash map lookup, Array return types.
4. Academic Conclusion

This project demonstrates how structured programming principles can be harnessed to build full-scale, responsive web ERP systems. By avoiding reliance on heavy external UI frameworks, the application achieves instantaneous execution times (< 1 ms for iterative searches), clean codebase architecture, and robust state persistence via localStorage.
